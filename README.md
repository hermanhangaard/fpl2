# FPL-tavle — Rullebrett

Ledertavle for FPL-ligaen «Rullebrett», publisert på **fpl.hangaard.no**.

Dette repoet inneholder **kun konfigurasjon og data**. Selve koden bor i
[hermanhangaard/fpl](https://github.com/hermanhangaard/fpl) og hentes ved
hvert bygg, så begge tavlene deler én kodebase og får samme forbedringer.

| Fil | Innhold |
|---|---|
| `konfig.json` | liga-ID |
| `CNAME` | custom domain |
| `design/` | bakgrunnsbilde |
| `data/` | fornavn, historikk og bufrede gameweeks — skrives av botten |
